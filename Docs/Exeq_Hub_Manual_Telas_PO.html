Fluxo — Novo prestador

  1. Menu Prestadores → Novo prestador.
  2. Informar CNPJ → consulta automática preenche razão social e endereço (quando disponível).
  3. Completar campos manuais: regime tributário, IE (se NF-e), IM (se NFS-e exigir), WhatsApp/contato.

  1. Menu Tomadores → Novo tomador.
  2. CNPJ: lookup Receita. CPF: preenchimento manual (LGPD).
  3. Endereço completo (necessário para NF-e; recomendado para NFS-e).
  4. Salvar.

7. Provedor de cobrança

Escolha e credenciais: Inter (padrão BolePix), Asaas ou C6.

Escolher provedor→ Credenciais / cert mTLS→ Testar conexão→ Nova cobrança
  1. Abrir Provedor de cobrança.
  2. Ativar o provedor desejado (cards Inter / Asaas / C6).
  3. Inter: client id/secret + certificado e chave mTLS (zonas de drop).
  4. Clicar Testar conexão (admin) — não devolve token na tela.
  5. Somente após OK: emitir cobranças com sucesso em ambiente real.
Em laboratório o Hub pode rodar gateway em modo stub (sem banco real). Na demo comercial, deixar claro se a cobrança é simulada ou sandbox Inter.

Fluxo — Nova cobrança

  1. Nova cobrança → escolher tomador, valor, vencimento, descrição.
  2. Tipo: única, parcelada ou recorrente (Hub orquestra N boletos no gateway).
  3. Confirmar. Status inicial tipicamente aberta / registrada.
  4. No detalhe: baixar PDF do boleto, copiar linha/PIX (se o gateway retornar), sincronizar status.
  5. Cancelamento: motivo obrigatório no Inter (modal de cancelamento).
Status pago só entra via webhook/evento de pagamento — não marca-se “à mão” no Hub.

Fluxo — Emitir

Emitir NFS-e→ Prestador + Tomador + Serviço + Valor→ Enfileira (Celery)→ Processando→ Autorizada→ PDF + XML
  1. Clique Emitir NFS-e (modal).
  2. Selecionar prestador, tomador, item de serviço, valor e competência.
  3. Confirmar. A emissão é assíncrona — status acompanha automaticamente na lista.
  4. Quando Autorizada: ações de baixar PDF (DANFSe) e XML.
  5. Se processando: ícone de atualizar status (poll).
  6. Cancelar: justificativa ≥ 15 caracteres (modal de cancelamento).
Texto de UI pode citar “Focus” no subtítulo do layout; a estratégia de produto é emissor próprio Nacional no piloto. Na demo, alinear a narrativa com o ambiente do cliente.

Fluxo — Emitir NF-e (stub ou HTTP)

  1. Conferir gate: se botão Nova NF-e estiver desabilitado, corrigir itens em vermelho no box T0.
  2. Cadastrar produto fiscal (se lista vazia).
  3. Nova NF-e → destinatário + itens → salvar rascunho.
  4. Validar (regras Hub) → Transmitir (confirmação).
  5. Acompanhar processando → autorizada / rejeitada / denegada.
  6. Autorizada: baixar XML e DANFE; se PDF pendente, usar Regenerar DANFE.
  7. Pós-autorização (quando permitido): Cancelar, CCe, e-mail de artefatos.
Narrativa PO: não apresente NF-e como “produção em todos os clientes” enquanto G-EMIT (1ª autorizada SEFAZ-SP real) não estiver fechado. Em lab: stub funciona de ponta a ponta com número e DANFE simulados.
